Templates for `/new-component`. Copy into `src/widgets/<category>/<component>/`, drop the `.tmpl` suffix, and replace:

- `__Name__`: PascalCase component name (e.g. `CardsCarousel`)
- `__Display Name__`: human name (e.g. `Cards Carousel`)
- `__slug__`: folder name (e.g. `cards-carousel`)
- `__prefix__`: CSS class prefix used by the real widget (e.g. `carousel`)
- `__widgetId__`: default widget ID (e.g. `customCardsCarousel`)
